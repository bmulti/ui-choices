[intro] # UI Choices — the shared appearance and interface-state panel cpc_ui_choices is the common UI Choices panel for Tkinter applications. It lets a user pick a theme and density, adjust fonts and appearance, choose a notes language, capture screenshots, and produce a one-page report of the application's identity, version and settings. It plugs into an existing application tab and updates the application's own config dictionary using the long-standing common keys, so an application does not have to replace its own configuration. Running cpc_ui_choices.py directly opens the standalone UI Choices manager, with UI Choices, Config and Gateway tabs. Importing the module in another application opens nothing by itself. # Quick start Create a tab, then attach the panel: panel = cpc_ui_choices.attach(tab, window=root, config=config, save_callback=save_my_config, app_name="My App") panel.pack(fill="both", expand=True) The config dictionary is updated in place. Pass save_callback so Apply and Save can write your own settings file. attach never raises: if the panel cannot start, a short notice is shown instead and the application carries on (see Failure behaviour below). At start-up you can apply auto day/night before building the window: name = cpc_ui_choices.auto_theme_choice(config) or config.get("ui_theme_name") # Keys the panel reads and writes in your config ui_theme_name, ui_density, appearance, window_title, window_width, window_height, last_tab, last_subtab, last_record_id, language, auto_theme, screenshot_start_delay and screenshot_screen_delay. Other application values in the same dictionary are left alone. # Failure behaviour — the shared settings are fail-safe UI Choices must never stop an application from starting or lose a change. - Missing, empty or damaged settings files give defaults, never an error. A damaged file is moved aside as name.corrupt-<date>-<time>, not deleted, and the last good copy (name.bak) is used if there is one. - A settings section of the wrong type is replaced by its default. - Reading or writing the shared file is time-limited (about 3 seconds). An unreachable network drive is skipped for 90 seconds, so start-up cannot hang, and a per-user local copy of the settings is used instead. - If the shared folder is read-only or unreachable when you save, the change is saved to another allowed location or the local copy, and it is copied to the shared file the next time it is reachable. - Missing optional modules (cpc_ui_theme, cpc_ui_state, the gateway controller, Pillow) reduce features; they do not prevent the panel opening. - If the panel itself fails to build, attach shows a notice and records the details in cpc_ui_choices.ATTACH_ERRORS. Use "Copy details" on the notice. [tab:explore] # Explore — try the panel Standard, Quick: point at a theme tile to preview it in the live sample on the right; click to keep it; Apply commits the choice to the application. Revert to saved theme returns to the theme saved on disk. Each tile shows the theme number. Contact sheet draws every theme, with number and name, to a PNG; on All themes it draws only the themes matching the filter. Standard, Auto: choose a light theme for the day and a dark theme for the night. The application follows the operating system's light or dark setting, or the time of day (24-hour HH:MM). If the operating system setting cannot be read, the time of day is used. It re-checks every 30 seconds while the window is open and only switches when day changes to night or back, so a theme you choose by hand is not overridden. Expert Appearance: fonts, theme builder and the detailed colour controls. Languages: choose the notes language; translations are files named <application>.<code>.txt beside the application, with the [intro], [footer] and [tab:...] identifiers unchanged. English is the fallback. Screenshots: capture the current screen, or every tab. During the start delay you may switch to any other screen; the countdown shows in the title bar and the current screen at that moment is captured. Pictures are saved beside the application as <file>.<application>.<screen>.png. Open in Explorer selects the file, Copy image puts the picture on the clipboard, and Attach config / version info saves a copy with the identity and settings added below the picture and embedded in the PNG. Report: gathers the application identity and version trace, system details, settings changed from the defaults and since the last report, a check of Treeview odd/even colours, and the configuration (passwords, tokens, keys and connection-string passwords are hidden). Write what went wrong, then save a one-page HTML file or a zip bundle (HTML, JSON, text and an optional screenshot) to send to someone. # Where settings are stored The global settings file is ui_choices_global.json. A relative location is never taken from the current working directory, which changes with every shortcut and tool. For reading, the first existing file is used from: the location in CPC_UI_CHOICES_CONFIG, the folder of the running application, the folder beside cpc_ui_choices.py, then the per-user local copy. Saving prefers the folder beside cpc_ui_choices.py (so a shared library keeps one shared file), then the application folder, then the local copy. The local copy lives in the user's data folder under cpc_ui_choices (LOCALAPPDATA on Windows). cpc_ui_theme reads its shipped baseline from the same folder beside the module, so both modules agree on the file. Call global_config_status() to see which file is in use and any problems that were handled. # Guide pages, posters and application JSON APP_GUIDE_ROOT, APP_GUIDE_POSTER_ROOT and APP_JSON_ROOT may be absolute paths, file: or http(s) addresses, or relative folders. Relative folders are looked for beside the module and the running application and used as absolute locations (the working directory is only a last resort here, and is never used for the settings file); resolve_path and resolve_guide_root expose this. [tab:api-reference] # API Reference — read the actual code Public names in this module: attach, UIChoicesPanel, UIChoicesApplication, load_global_config, save_global_config, global_config_path, global_config_candidates, global_config_status, application_config, save_application_config, resolve_path, resolve_guide_root, user_data_dir, auto_theme_choice, auto_theme_state, os_prefers_dark, splash, ATTACH_ERRORS. load_global_config and save_global_config accept an optional explicit path; with an explicit path no fallback is used. Both return normally on any failure: load gives defaults and save returns False. [tab:framework-standard] # Framework Standard — application shell contract cpc_theme_standard.md is the full shared Tkinter application guide. Its sections on Config versus UI Choices, window state, remembered tabs and shared appearance describe how this panel is meant to be used. UI Choices holds appearance and interface state; application-specific behaviour, folders and data sources belong under Config. [tab:config] # Config — the global settings file ui_choices_global.json holds shared defaults: ui_defaults (theme, density, fonts), startup (splash times and height), about (guide, poster and application JSON locations, support link), gateway and gateway_storage, gateway_behaviour, performance, and an applications section with one entry per application. Applications keep their own values there through save_application_config. The standalone Config tab edits the same file. # Careful with Do not copy the theme tables or settings into individual applications. If a settings file is damaged it is preserved with a .corrupt suffix; check global_config_status() before deleting anything. [tab:ui-choices] # UI Choices — this panel This is the panel the other notes describe. Appearance values chosen here are saved in the application's config and re-applied the next time it starts. Notes in other languages are saved as cpc_ui_choices.<code>.txt beside the module. [tab:about] # About — source identity and version About shows which source file is running, its declared version, the config file and its modification time, the machine and user, and the guide and poster locations. The same details appear in the Report tab and in the banner added to a screenshot, so a recipient can tell which version produced it. It is not involved in saving or restoring appearance, and its absence does not affect UI Choices. [footer] [Mr Bmulti](https://mrBmulti.com) [GitHub](https://github.com)

[intro] # UI Choices — gipaambit nga panel sa hitsura ug kahimtang sa interface Ang cpc_ui_choices mao ang komon nga UI Choices panel alang sa mga aplikasyon nga Tkinter. Idugtong kini sa usa nang tab sa aplikasyon ug direkta nga bag-ohon ang kaugalingong config dictionary niini gamit ang dugay nang gigamit nga komon nga mga key, busa dili kinahanglan ilisan ang sistema sa configuration sa aplikasyon. Ang direktang pagpadagan sa cpc_ui_choices.py mag-abli sa independente nga UI Choices manager nga adunay UI Choices, Config ug Gateway nga mga tab. 設定の保存場所 グローバル設定ファイルは ui_choices_global.json です。相対パスを現在の作業ディレクトリから解決することはありません。作業ディレクトリはショートカットやツールによって変わるためです。読み込み時は次の順序で最初に存在するファイルを使用します。CPC_UI_CHOICES_CONFIG が示す場所、実行中のアプリケーションのフォルダー、cpc_ui_choices.py の隣のフォルダー、ユーザーのローカルコピーです。保存時は cpc_ui_choices.py の隣を優先し（共有ライブラリで共通ファイルを一つに保つため）、次にアプリケーションのフォルダー、最後にローカルコピーを使います。ローカルコピーはユーザーデータフォルダー内の cpc_ui_choices にあり、Windows では LOCALAPPDATA を使用します。 cpc_ui_theme も、配布時の基準設定をモジュールの隣の同じフォルダーから読み込むため、二つのモジュールは同じファイルを参照します。global_config_status() を呼ぶと、使用中のファイルと対処済みの問題を確認できます。 # [intro] # UI Choices — 공용 모양 및 인터페이스 상태 패널 cpc_ui_choices는 Tkinter 애플리케이션에서 사용하는 공용 UI Choices 패널입니다. 사용자는 테마와 표시 밀도를 선택하고, 글꼴과 모양을 조정하고, 노트 언어를 지정하고, 화면을 캡처하고, 애플리케이션의 식별 정보·버전·설정을 한 페이지 보고서로 만들 수 있습니다. 기존 탭에 연결하여 오랫동안 사용해 온 공통 키로 애플리케이션 자체의 config 사전을 직접 갱신하므로, 기존 설정 체계를 교체할 필요가 없습니다. cpc_ui_choices.py를 직접 실행하면 UI Choices, Config, Gateway 탭이 있는 독립형 UI Choices 관리자가 열립니다. 다른 애플리케이션에서 모듈을 가져오기만 하면 창이 자동으로 열리지는 않습니다. # 빠른 시작 탭을 만들고 패널을 연결합니다. panel = cpc_ui_choices.attach(tab, window=root, config=config, save_callback=save_my_config, app_name="My App") panel.pack(fill="both", expand=True) config 사전은 제자리에서 갱신됩니다. Apply와 Save가 해당 애플리케이션의 설정 파일을 기록할 수 있도록 save_callback을 전달하세요. attach는 호출자에게 예외를 전달하지 않습니다. 패널을 시작하지 못하면 간단한 안내를 표시하고 애플리케이션은 계속 실행됩니다(아래 오류 발생 시 동작 참조). 시작할 때 창을 만들기 전에 자동 주간/야간 테마를 적용할 수 있습니다. name = cpc_ui_choices.auto_theme_choice(config) or config.get("ui_theme_name") # 패널이 config에서 읽고 쓰는 키 ui_theme_name, ui_density, appearance, window_title, window_width, window_height, last_tab, last_subtab, last_record_id, language, auto_theme, screenshot_start_delay, screenshot_screen_delay. 같은 사전에 있는 나머지 애플리케이션 값은 변경하지 않습니다. # 오류 발생 시 동작 — 안전한 공용 설정 UI Choices는 애플리케이션 시작을 막거나 변경 내용을 잃게 해서는 안 됩니다. - 설정 파일이 없거나 비었거나 손상되면 오류 없이 기본값을 사용합니다. 손상 파일은 삭제하지 않고 name.corrupt-<date>-<time>이라는 이름으로 따로 보관하며, 마지막 정상 복사본(name.bak)이 있으면 사용합니다. - 설정 섹션의 자료형이 잘못되면 해당 기본값으로 교체합니다. - 공용 파일 읽기와 쓰기에는 약 3초의 시간 제한이 있습니다. 접근할 수 없는 네트워크 드라이브는 시작이 멈추지 않도록 90초 동안 건너뛰며 사용자별 로컬 설정 복사본을 대신 사용합니다. - 저장 시 공용 폴더가 읽기 전용이거나 접근할 수 없으면 허용된 다른 위치 또는 로컬 복사본에 변경 내용을 저장하고, 공용 파일에 다시 접근할 수 있을 때 복사합니다. - 선택적 모듈(cpc_ui_theme, cpc_ui_state, Gateway 컨트롤러, Pillow)이 없으면 일부 기능만 제한되며 패널을 여는 데는 지장이 없습니다. - 패널 자체를 만들지 못하면 attach가 안내를 표시하고 세부 내용을 cpc_ui_choices.ATTACH_ERRORS에 기록합니다. 안내의 Copy details를 이용하세요. 故障处理 — 共享设置具有容错能力 UI Choices 不应阻止应用程序启动，也不应丢失已作出的修改。 - 设置文件缺失、为空或损坏时，直接采用默认值，不引发错误。损坏文件会移到一旁并命名为 name.corrupt-<date>-<time>，而不是删除；如果存在最后一份有效备份 name.bak，就使用该备份。 - 配置段的数据类型不正确时，会以相应的默认值替换。 - 共享文件的读取和写入设有时间限制（约 3 秒）。无法访问的网络驱动器会被跳过 90 秒，以免启动过程卡住；期间改用每位用户的本地设置副本。 - 保存时如果共享文件夹为只读或无法访问，修改会先保存在其他允许的位置或本地副本中，待共享文件重新可访问时再复制过去。 - 缺少可选模块（cpc_ui_theme、cpc_ui_state、Gateway 控制器或 Pillow）只会减少部分功能，不会阻止面板打开。 - 如果面板本身创建失败，attach 会显示提示，并将详细信息记录到 cpc_ui_choices.ATTACH_ERRORS。可以点击提示中的 Copy details。 [tab:explore] # Explore — 体验面板 Standard、Quick：将鼠标移到主题方块上，右侧的实时示例会预览该主题；点击方块可保留选择，再通过 Apply 应用到程序。Revert to saved theme 恢复磁盘上已保存的主题。每个方块都显示主题编号。Contact sheet 会把所有主题的编号和名称绘制到 PNG 图像中；在 All themes 模式下，仅绘制符合筛选条件的主题。 Standard、Auto：为白天选择浅色主题，为夜间选择深色主题。应用程序根据操作系统的浅色／深色模式，或一天中的时间（24 小时制 HH:MM）切换。如果无法读取系统偏好，就按时间判断。窗口打开期间每 30 秒检查一次，但只在白天与夜间相互转换时切换，因此不会覆盖用户手动选择的主题。 Expert Appearance：设置字体、构建主题并使用详细的颜色控制。Languages：选择说明文字的语言；翻译文件应放在应用程序旁，命名为 <application>.<code>.txt，且保持 [intro]、[footer] 和 [tab:...] 标识符不变。缺少对应翻译时会回退到英语。 Screenshots：截取当前屏幕或每个选项卡。启动延迟期间可以切换到任何其他屏幕；标题栏会显示倒计时，到达截取时间时会捕获当时显示的屏幕。图片以 <file>.<application>.<screen>.png 的名称保存在应用程序旁。Open in Explorer 会定位并选中文件；Copy image 将图片复制到剪贴板；Attach config / version info 则保存另一份图片，在图片下方附加身份及设置信息，并将这些信息嵌入 PNG 文件。 Report：汇总应用程序身份和版本记录、系统信息、与默认值不同的设置、上次报告以来的变更、Treeview 奇偶行颜色检查以及配置信息（密码、令牌、密钥和连接字符串中的密码会被隐藏）。描述发生的问题后，可保存一页 HTML 报告，或包含 HTML、JSON、文本以及可选截图的 ZIP 压缩包，以便发送给他人。 # 设置保存在哪里 全局设置文件名为 ui_choices_global.json。相对路径绝不会以当前工作目录为依据，因为该目录会随快捷方式和工具而改变。读取时依次查找以下位置，并采用第一个存在的文件：CPC_UI_CHOICES_CONFIG 指定的位置、正在运行的应用程序目录、cpc_ui_choices.py 所在目录，最后是每位用户的本地副本。保存时优先使用 cpc_ui_choices.py 所在目录（使共享库只维护一份共享文件），其次是应用程序目录，最后才是本地副本。本地副本位于用户数据目录下的 cpc_ui_choices 文件夹（Windows 使用 LOCALAPPDATA）。 cpc_ui_theme 从该模块旁的同一目录读取随附的基础配置，因此两个模块使用一致的文件。调用 global_config_status() 可查看实际使用的文件及已处理的问题。 #
